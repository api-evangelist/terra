# Terra Security

> Terra Security operates an agentic-AI-powered continuous offensive security (penetration testing) platform. A swarm of AI agents continuously validates every attack surface — web applications, external and internal networks, and AI systems (LLMs, copilots, MCPs, agents) — with a human-on-the-loop workflow. Founded in 2024 (Tel Aviv), backed by Felicis. Terra publishes no public developer API; this file is generated from the API Evangelist catalog for discovery.
